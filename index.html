    How I built it

    Where the problem came from

    I opened a fresh Angel One account on 11 Nov 2026 and walked the IPO journey: the Jio Platforms page, the help centre, Ask Angel and my empty portfolio. I asked Ask Angel real questions, spoke to a friend who'd applied for an IPO, and checked the numbers against SEBI's IPO study and Angel One's own filings.

    What I built

    • A single web page, no backend. Every screen, both scenarios and both languages run in the browser.
    • Next steps are picked by simple fixed rules, not by AI, so nothing reads as investment advice.
    • Ask Angel's answers here are scripted to show the bar the real model must meet. The evals tab shows how I'd test it.
    • I wrote the spec, copy and numbers myself, and used AI coding tools to build and polish the UI faster.

    What I'd do next

    • Pull the Jio cohort's 30-day activity with SQL to replace my estimates.
    • Fix Ask Angel's refund answer first. It's a quick win that builds trust.
    • Run the 50/50 holdout at the next big IPO and track the guardrails.
