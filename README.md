# nextstep: a concept for Angel One

Product case prototype by Tanay Saxena (Angel One Product Intern, PS-II 2027).

**Problem:** at the IPO money moment (refund or listing gain), the app gives no next step, so an IPO wins Angel One an account, not an investor.

**What's here:** a single `index.html` with no backend.
- Landing page: the evidence, before vs after, how it works, sizing.
- `#demo`: live phone demo. Switch between not allotted and allotted, next step on or off (off = today's journey), and English or Hindi.
- Ask Angel evals, an impact calculator, and how it was built.

**Run locally:** open `index.html` in a browser.

**Deploy:** Netlify, publish directory `/`, no build command.

Concept only. Not an official Angel One product. Not investment advice.
